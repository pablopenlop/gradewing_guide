# The Custom Subjects Guide


!!! tip "Keep your custom subjects DRY (Don't Repeat Yourself)"
    Do not create copies of the same subject for each year of e.g. Lower Secondary (KS3). Instead, create a *single* subject and enrol students in it for all three Lower Secondary years. The only reason to create separate copies of subjects for each year is if you want to use *different* grading scales across the years, which is not common practice.
